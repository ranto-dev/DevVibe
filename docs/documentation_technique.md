# DevVibe - Documentation technique

## Introduction

DevVibe est une application mobile open-source développée en Kotlin pour Android. Elle vise à améliorer la concentration et la productivité des développeurs en créant un environnement de travail optimisé.

## Objectifs

- Favoriser l’état de flow
- Structurer les sessions de travail
- Suivre les performances de concentration
- Créer une routine productive durable

## Cible

- Développeurs
- Étudiants
- Créateurs de contenu

## Stack technique

- Kotlin 2.3.0
- Gradle 9.4.0
- Plateforme : Android SDK 20.0
- UI : Material Design Components 1.11.0
- JVM 17.0.18

## Architecture du projet

### Structure des dossiers

```
/app
|- src/
    |- main/
        |- java/com.ranto.devvibe
            |- activities
            |- adapters
            |- managers
            |- models
            |- receivers
            |- services
            |- utils
            MainActivity.kt
        |- res/
        |- AndroidManifest.xml
```

## Fonctionnalités principales

1. Audio Focus

 - Lecture de musique Lofi
 - Streaming continu
 - Amélioration de la concentration

2. Time Blocking

 - Sessions de travail personnalisées
 - Gestion des pauses
 - Mode type Pomodoro

3. Statistiques

 - Temps total de concentration
 - Nombre de sessions
 - Streak journalier

4. Motivation

 - Citations quotidiennes
 - Renforcement de l’engagement
